# Support

| What you need | Where |
|---|---|
| A bug in one of our tools | That repository's issues |
| The network: endpoints, tokens, chain parameters | [basisnetwork.com.co/docs](https://basisnetwork.com.co/docs) |
| A security vulnerability | security@basisnetwork.com.co — never a public issue |
| A code of conduct concern | conduct@basisnetwork.com.co |
| Anything else | contact@basisnetwork.com.co |

This is maintained by a small team and there is no support contract. Issues
are read; nothing is guaranteed. Security reports are the exception and have
published response times in [SECURITY.md](./SECURITY.md).
